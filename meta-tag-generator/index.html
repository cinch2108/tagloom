Meta Tag Generator with Google SERP Preview

How it works

Type a page title and meta description and Tagloom measures them in pixels, the way Google does, using the same Arial font sizes as the results page. You see a live desktop or mobile search snippet with the exact point where Google would cut the text, color-coded length meters, and a ready-to-paste block of title, description, canonical, robots, viewport, charset and hreflang tags.

How to use it

  1. Enter your page title and meta description.
  2. Add the canonical URL and pick robots options such as noindex or nofollow if you need them.
  3. Check the desktop and mobile SERP preview and shorten anything shown with “...”.
  4. Optionally add hreflang lines for translated versions of the page.
  5. Copy the generated tags into your page's <head>.

Frequently asked questions

How long should a title tag be?

Google cuts desktop titles at about 600 pixels, which is usually 50–60 characters. Wide letters like W and M use more space than i or l, so measuring pixels is more reliable than counting characters.

How long should a meta description be?

Aim for about 120–158 characters. Google truncates desktop descriptions at roughly 920 pixels and often rewrites them, so put the most important words first.

Do meta keywords still matter?

No. Google has ignored the meta keywords tag for years, so Tagloom doesn't generate it.

What does the canonical tag do?

It tells search engines which URL is the main version of a page, so duplicates like tracking-parameter URLs pass their signals to it.

Is anything I enter uploaded?

No. Tagloom runs entirely in your browser. Nothing you type, paste or pick is sent to a server, and it keeps working offline once the page has loaded.
