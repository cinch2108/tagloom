Nginx Redirect and Server Block Generator

How it works

Generate nginx server blocks that redirect HTTP to HTTPS, pick www or non-www, add or strip trailing slashes, serve a custom 404, enable gzip, set long cache headers for static files, add security headers and apply exact-match 301 or 302 redirects with location blocks.

How to use it

  1. Pick the nginx format and enter your domain.
  2. Choose HTTPS, www and trailing-slash options.
  3. Add your redirects.
  4. Copy the config into /etc/nginx/sites-available.
  5. Run nginx -t, then reload nginx.

Frequently asked questions

How do I test an nginx config?

Run sudo nginx -t to check the syntax, then sudo systemctl reload nginx to apply it without downtime.

Why use return instead of rewrite?

return 301 is faster and clearer for simple redirects; rewrite is only needed for pattern-based changes.

Where do the SSL certificate lines go?

Fill in the commented ssl_certificate lines with your certificate paths, for example from Let's Encrypt.

Is anything I enter uploaded?

No. Tagloom runs entirely in your browser. Nothing you type, paste or pick is sent to a server, and it keeps working offline once the page has loaded.
