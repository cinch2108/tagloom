Sitemap Index Generator for Large Sites

How it works

For sites with more than 50,000 URLs, Tagloom splits your list into numbered sitemap files of up to 50,000 URLs each (and under 50 MB), then writes a sitemap_index.xml that points to all of them. Everything downloads together as one ZIP, ready to upload to your site root.

How to use it

  1. Paste or load your full URL list.
  2. Set the base URL where the sitemap files will live.
  3. Generate the files and check the split count.
  4. Download the ZIP.
  5. Upload all files and submit sitemap_index.xml.

Frequently asked questions

What is a sitemap index?

An XML file that lists other sitemap files, so you can submit one URL for a site with millions of pages.

Can a sitemap index list another index?

No. A sitemap index can only list sitemaps, not other indexes.

Where should the files be hosted?

Usually in the site root. A sitemap can only list URLs in its own directory and below.

Is anything I enter uploaded?

No. Tagloom runs entirely in your browser. Nothing you type, paste or pick is sent to a server, and it keeps working offline once the page has loaded.
