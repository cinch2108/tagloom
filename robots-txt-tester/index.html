Robots.txt Tester: Check if a URL Is Blocked

How it works

Paste a robots.txt file, pick a crawler like Googlebot or GPTBot, and enter a URL. Tagloom picks the matching user-agent group, applies the longest matching Allow or Disallow rule (Allow wins ties), supports * and $ wildcards, and tells you which line decided the result. You can bulk-test a list of paths too.

How to use it

  1. Paste your robots.txt or build one in the generator tab.
  2. Choose or type a user-agent.
  3. Enter a URL or path to test.
  4. Read the verdict and the rule that decided it.
  5. Bulk-test a list of important paths.

Frequently asked questions

How does Google pick which rule applies?

It uses the most specific matching rule, meaning the longest path. If an Allow and a Disallow rule are equally long, Allow wins.

What if no group matches my crawler?

The crawler follows the * group. If there is no * group either, everything is allowed.

Are robots.txt paths case-sensitive?

Yes. /Page and /page are different paths. User-agent names are not case-sensitive.

Is this the same as Google Search Console?

It follows the same published rules (RFC 9309), but Search Console's report shows what Google actually fetched from your live site.

Is anything I enter uploaded?

No. Tagloom runs entirely in your browser. Nothing you type, paste or pick is sent to a server, and it keeps working offline once the page has loaded.
