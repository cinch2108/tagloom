Hreflang Tag Generator for Multilingual Sites

How it works

List each language or regional version of a page as “language-code URL” and Tagloom validates the codes (like en, en-GB, es-419 or x-default), checks that every URL is absolute, and writes matching link rel=alternate hreflang tags together with the rest of your meta tags.

How to use it

  1. Enter the page's canonical URL.
  2. Add one line per version, for example: en-GB https://example.com/uk/
  3. Include an x-default line for the fallback page.
  4. Fix any lines marked as invalid.
  5. Paste the same set of tags on every language version.

Frequently asked questions

What is hreflang?

An HTML attribute that tells search engines which language and region a page is for, so users see the right version in their results.

Do the tags need to be on every version?

Yes. Each version should list all versions, including itself. Missing return links make Google ignore the annotations.

What is x-default?

The page to show users whose language or region doesn't match any listed version, often a language selector or the main site.

Should I use country codes alone?

No. hreflang needs a language code; a region is optional. “en-US” is valid, “us” is not.

Is anything I enter uploaded?

No. Tagloom runs entirely in your browser. Nothing you type, paste or pick is sent to a server, and it keeps working offline once the page has loaded.
