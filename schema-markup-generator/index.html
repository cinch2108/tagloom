Schema Markup Generator for JSON-LD

How it works

Build schema.org structured data as JSON-LD for 12 types: Organization, LocalBusiness, Article, Product, FAQPage, HowTo, BreadcrumbList, Event, Recipe, Person, WebSite with SearchAction, and VideoObject. Required fields are flagged, URLs and numbers are validated, empty fields are dropped, and the output is checked as valid JSON before you copy it.

How to use it

  1. Choose a schema type.
  2. Fill in the fields; required ones are marked with *.
  3. Fix any warnings shown above the code.
  4. Copy the script tag into your page.
  5. Test it with Google's Rich Results Test.

Frequently asked questions

What is JSON-LD?

A way of adding structured data to a page in a script tag, separate from your HTML. It's the format Google recommends.

Does schema markup improve rankings?

Not directly, but it can make pages eligible for rich results like stars, prices and recipe cards, which can lift clicks.

Can a page have more than one schema?

Yes. Add one script tag per item, for example Organization, BreadcrumbList and Article on the same page.

Why won't Google show my rich result?

Valid markup makes a page eligible, but Google decides whether to show rich results based on quality and relevance.

Is anything I enter uploaded?

No. Tagloom runs entirely in your browser. Nothing you type, paste or pick is sent to a server, and it keeps working offline once the page has loaded.
